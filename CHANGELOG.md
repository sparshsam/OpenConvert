# Changelog

## 0.1.0 - 2026-06-13

Initial public AGPL-3.0 release.

- Added Windows-first Tauri desktop app
- Added native menu toolbar
- Added local image-to-image conversion for PNG, JPG/JPEG, WEBP, BMP, and TIFF
- Added drag-and-drop upload and manual file picker
- Added output folder selection
- Added safe output naming that never overwrites existing files
- Added durable local conversion history with redacted fields only
- Added Clear History action
- Added About dialog
- Added GitHub Releases updater configuration
- Added Windows installer/release workflow
