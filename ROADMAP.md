# Roadmap

## v0.1.x

- Harden updater release signing and release documentation
- Improve metadata preservation where supported by encoders
- Add stronger UI coverage around drag-and-drop and menu events
- Add more sample image conversion fixtures for regression testing

## Future Versions

- Batch image conversion
- More image metadata controls
- Output quality controls for JPG and WEBP
- Additional desktop polish for keyboard accessibility

## Explicit Non-Goals for v0.1.0

- Audio conversion
- Video conversion
- PDF conversion
- Document conversion
- Batch conversion
- OCR
- Mobile app
- Accounts
- Cloud processing
- Telemetry
- Plugins
