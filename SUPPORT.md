# Support

## Getting Help

If you need help with OpenConvert, here are the best ways to find it:

### Documentation

- **[README.md](README.md)** — Getting started, installation, and feature overview.
- **[ROADMAP.md](ROADMAP.md)** — Planned features and project direction.
- **[CHANGELOG.md](CHANGELOG.md)** — Version history and release notes.

### Issues

- Search [existing issues](https://github.com/sparshsam/OpenConvert/issues)
  before opening a new one.
- If you do not find an existing issue, [open a new one](https://github.com/sparshsam/OpenConvert/issues/new).

### Feature Requests

Feature requests are welcome. Please open an issue with the label
`enhancement` and describe the use case clearly. Keep in mind the project's
scope and non-goals as documented in the [ROADMAP](ROADMAP.md).

### Community and Discussions

GitHub Discussions are not yet enabled for this repository. For now, please use
the issue tracker for questions and feedback.

### Commercial Support

For commercial support inquiries, please contact the maintainer directly via
GitHub: [@sparshsam](https://github.com/sparshsam).
